# 출석 · 수업료 관리

아동 치료 센터용 출석 체크 및 월 수업료 산정 웹 앱입니다.

## 사용 방법

1. GitHub Pages로 배포된 주소(`https://...github.io/...`)로 접속합니다. (`index.html`을 로컬에서 더블클릭해서 열면 브라우저 보안 정책 때문에 데이터를 불러오지 못합니다.)
2. 선생님 이름과 4자리 비밀번호로 로그인합니다.
3. 데이터는 Supabase 데이터베이스에 실시간으로 저장되어, 어떤 기기로 접속해도 같은 데이터를 봅니다.

## 메뉴 구성

| 탭 | 내용 |
|----|------|
| 오늘 출석 | 날짜를 옮겨가며 출석/결석 체크(시간순 정렬) + 보강 인원 추가(ㄱㄴㄷ순) |
| 시간표 | 등록된 수업 시작 시간(수업당 40분) 기준 월~토 시간대별 시간표, A4 세로 인쇄/PDF 저장 |
| 대상자 관리 | 대상자 등록/수정/삭제, 결제 구분(바우처) 설정, 최신순/이름순 정렬 |
| 월 수업료 산정 | 월별 수업료·본인부담금 계산 및 입금일·실제 납부액 기록, 대상자 직접 선택 |
| 월 출석부 | 월별 날짜별 출석/결석(사유) 현황표 |
| 선생님 관리 (관리자 전용) | 선생님 추가/삭제, 비밀번호 변경, 관리자 권한 지정 |

**관리자(신승오)는 모든 선생님의 대상자·시간표·월 출석부·월 수업료를 다 볼 수 있습니다.** 일반 선생님은 로그인하면 본인이 담당하는 대상자만 보입니다.

## 요일별 수업 시간 설정

대상자 등록/수정 시 "수업 요일 및 시간"에서 월~토(일요일 제외) 중 요일을 체크하고, **요일마다 서로 다른 시간**을 설정할 수 있습니다. (예: 월요일 14:00, 수요일 16:30)

- 시간표, 오늘 출석, 대상자 관리 목록에 모두 요일별 시간이 반영됩니다.
- 기존에 등록된 대상자(요일별 시간 없이 단일 시간만 있던 경우)는 자동으로 모든 요일에 같은 시간이 적용된 것으로 처리되어, 별도 작업 없이 그대로 열람·수정하실 수 있습니다.

> `sql/2026-09-02-day-times.sql`을 Supabase SQL Editor에서 실행하면 `children` 테이블에 `day_times` 컬럼이 추가되고 기존 데이터도 요일별 시간 형식으로 변환됩니다. 실행하지 않아도 앱이 자동으로 예전 데이터를 호환 처리하지만, 실행해두면 이후 관리가 더 깔끔합니다.

수업 시간은 10분 단위로만 입력할 수 있습니다.

## 오늘 출석 - 날짜 이동

출석 체크를 놓친 날이 있을 수 있어, **오늘 출석** 탭에서 ◀ ▶ 버튼으로 다른 날짜로 이동해 그날의 출석을 체크/수정할 수 있습니다. `오늘` 버튼으로 바로 오늘 날짜로 돌아올 수 있고, 탭을 처음 열면 항상 오늘 날짜가 먼저 보입니다.

- 출석 대상자 목록은 수업 시간 순서로 정렬됩니다.
- `+ 보강 인원 추가` 드롭다운에는 그날 목록에 없는 등록된 대상자 전원이 이름(ㄱㄴㄷ) 순으로 나옵니다.
- 보강으로 추가한 기록은 날짜별로 따로 관리되어, 다른 날짜로 이동해도 섞이지 않습니다.

## 월 수업료 산정 - 대상자 선택

월 수업료 산정 탭 상단 체크박스에서 이번에 계산/확인할 대상자를 직접 선택할 수 있습니다. 기본은 전체 선택 상태이며, 필요 없는 대상자는 체크를 해제해 목록에서 숨길 수 있습니다. `전체 선택`/`전체 해제` 버튼으로 한 번에 전환할 수 있습니다. (인쇄나 엑셀 내보내기와는 무관하게, 화면에 보이는 대상만 필터링합니다.)

## 납부액 수정 및 연간 납부 내역 조회

- **월 수업료 산정** 탭에서 추가금/본인부담금 입금일 옆에 금액 입력란이 있어, 계산된 금액을 그대로 두거나 실제 받은 금액으로 수정해서 저장할 수 있습니다.
- **대상자 관리** 또는 **월 수업료 산정**에서 대상자 이름을 클릭하면, 그 대상자의 연간(1~12월) 추가금·본인부담금·합계를 표로 보여주는 창이 뜹니다. 맨 아래 합계 줄에서 연말정산용 전체 합계를 바로 확인할 수 있고, 연도 이동 버튼으로 다른 해도 볼 수 있습니다.

> 이 기능을 쓰려면 Supabase DB에 `sql/2026-08-22-fee-actual-amounts.sql`을
> SQL Editor에서 한 번 실행해 `monthly_fees` 테이블에 `additional_amount`,
> `copay_amount` 컬럼을 추가해야 합니다.

## 보강 인원 출석 체크

정해진 요일 외에 보강으로 오는 대상자를 그날 하루만 출석 목록에 추가할 수 있습니다.

- **오늘 출석** 탭 상단의 `+ 보강 인원 추가` 드롭다운에서 대상자를 선택하면 목록에 "보강" 배지와 함께 추가됩니다.
- 추가된 대상자도 다른 대상자와 똑같이 출석/결석 체크가 가능하고, 잘못 추가했으면 `제외` 버튼으로 뺄 수 있습니다 (이미 체크한 기록이 있으면 삭제 여부를 확인합니다).
- 보강으로 체크한 출석은 **월 출석부**에도 그날 칸에 "출석 (보강)"으로 함께 표시되고 출석 횟수·전체 합계에도 포함됩니다.

## 로그인 · 선생님 관리

로그인 가능한 선생님 목록은 더 이상 코드에 고정되어 있지 않고, **선생님 관리** 탭(관리자 전용)에서 직접 관리합니다.

- **추가**: 이름을 입력하고 필요하면 "관리자 권한"에 체크한 뒤 `+ 선생님 추가`를 누르면 최초 비밀번호 `0000`으로 등록됩니다.
- **삭제**: 퇴사 등으로 더 이상 로그인이 필요 없으면 `삭제` 버튼으로 제거합니다. 그 선생님이 담당하던 대상자·출석·수업료 기록은 그대로 남고, 로그인만 안 되게 됩니다. (본인 계정은 삭제 버튼이 보이지 않습니다.)
- **비밀번호 변경**: 각 선생님 줄에서 비밀번호를 수정하고 저장할 수 있습니다.
- **관리자 권한**: "관리자" 배지가 있는 선생님은 모든 대상자·시간표·월 출석부·월 수업료를 다 볼 수 있고, 일반 선생님은 본인 담당 대상자만 등록·수정·출석·수업료 확인이 가능합니다.

> 이 기능을 쓰려면 Supabase DB에 `sql/2026-09-02-teacher-management.sql`을
> SQL Editor에서 한 번 실행해 `teacher_passwords` 테이블에 `is_admin` 컬럼을 추가해야 합니다.
> (신승오를 관리자로 지정하고, 퇴사한 이희웅 선생님을 삭제하는 내용도 함께 들어있습니다.)

## 결제 구분 (바우처) 중복 선택

대상자 등록/수정 시 결제 구분은 **체크박스로 여러 개를 동시에 선택**할 수 있습니다.
(예: 발달바우처 + 스포츠바우처, 교육청 치료지원 + 스포츠바우처 등)

> 이 기능을 쓰려면 Supabase DB에 `sql/2026-08-20-multi-payment-types.sql`을
> SQL Editor에서 한 번 실행해 `children` 테이블에 `payment_types`,
> `developmental_sub`, `infant_sub` 컬럼을 추가하고 기존 데이터를 자동 변환해야 합니다.

## 수업료 계산 방식

1. **총 금액** = 수업 횟수 × 1회 치료비
2. **본인부담금** = 선택된 발달/영유아 바우처 형별 금액의 합 (**별도 납부**, 둘 다 선택 시 각각 합산). 발달바우처는 이용 횟수에 비례.
3. **6·7회차 추가금** = 발달바우처가 포함되어 있고 6회 이상 시 발생 (안내용 항목 — 아래 4번 계산식에 이미 포함되어 있어 별도로 더하지 않음)
4. **추가납부액** = 총 금액 − 발달바우처 지원금 − 발달바우처 본인부담금 − (교육청 치료지원/방과 후/스포츠바우처 등 다른 바우처 차감액 합계)
   - 발달바우처가 없으면 앞의 두 항은 0이 되어 "총 금액 − 다른 바우처 차감액"과 같아집니다.
   - 아무 바우처도 없으면(일반) 총 금액 전액이 추가납부액이 됩니다.
   - 계산 결과가 마이너스가 될 수 있으며, 그 경우 빨간색으로 마이너스 금액을 그대로 표시합니다 (예: 발달바우처로 충당하고도 스포츠바우처 차감액이 남는 경우).

입금일은 **추가금 입금일**과 **본인부담금 입금일**을 따로 기록합니다.

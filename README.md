# 출석 · 수업료 관리

아동 치료 센터용 출석 체크 및 월 수업료 산정 웹 앱입니다.

## 사용 방법

1. `index.html` 파일을 브라우저에서 엽니다.
2. 선생님 이름과 4자리 비밀번호로 로그인합니다.
3. 데이터는 브라우저 localStorage에 자동 저장됩니다.

## 로그인

| 아이디 | 역할 | 최초 비밀번호 |
|--------|------|---------------|
| 신승오 | **관리자** (전체 조회) | 0000 |
| 이희웅, 김윤수, 김다현, 김지영 | 담당 아이만 조회 | 0000 |

- 관리자(신승오)는 **비밀번호 관리** 탭에서 각 선생님 비밀번호를 변경할 수 있습니다.
- 일반 선생님은 본인 담당 아이만 등록·수정·출석·수업료 확인이 가능합니다.

## 결제 구분 (바우처) 중복 선택

아이 등록/수정 시 결제 구분은 **체크박스로 여러 개를 동시에 선택**할 수 있습니다.
(예: 발달바우처 + 스포츠바우처, 교육청 치료지원 + 스포츠바우처 등)

> 이 기능을 쓰려면 Supabase DB에 `sql/2026-08-20-multi-payment-types.sql`을
> SQL Editor에서 한 번 실행해 `children` 테이블에 `payment_types`,
> `developmental_sub`, `infant_sub` 컬럼을 추가하고 기존 데이터를 자동 변환해야 합니다.

## 수업료 계산 방식

1. **총 금액** = 수업 횟수 × 1회 치료비
2. **바우처 차감** = 선택된 유형별 지원 금액 합계 (총 금액에서 차감, 안내용 정보)
3. **6·7회차 추가금** = 발달바우처가 포함되어 있고 6회 이상 시 추가
4. **추가납부액**
   - 발달바우처가 포함된 경우 (다른 바우처와 함께 선택되어도): 6·7회차 이상 추가금 합산액만 (총 금액·다른 바우처 차감액은 청구하지 않음, 정보 표시만)
   - 발달바우처 없이 다른 바우처만 선택: 총 금액 − 바우처 차감액 합계
   - 아무 바우처도 선택하지 않음(일반): 총 금액 전액
5. **본인부담금** = 선택된 발달/영유아 바우처 형별 고정 금액의 합 (**별도 납부**, 둘 다 선택 시 각각 합산)

입금일은 **추가금 입금일**과 **본인부담금 입금일**을 따로 기록합니다.
